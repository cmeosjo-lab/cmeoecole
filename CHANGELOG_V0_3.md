# V0.3 — fonctions demandées

- Titre dynamique venant du PC Principal.
- Sourates en rideau depuis le Principal, avec numéro, arabe et nombre de versets.
- Versets De / À adaptés automatiquement à la Sourate choisie.
- Hizb en rideau avec numéro + nom arabe du Principal.
- Juz en rideau avec numéro + nom arabe du Principal.
- Incidents : nature en rideau, priorité, description.
- Suivi de leçons : matière en rideau puis leçon en rideau.
- Absence : date + justifiée/non justifiée.
- Retard : date + justifié/non justifié + heure d'arrivée obligatoire.
- File hors connexion et accusé de réception du Principal.
- `deviceId` pour préparer le multi-appareils et la reprise sur PC Prof.
- Android 17 : permission LAN préparée.
- iOS : déclaration réseau local préparée.
- QR code facultatif, code professeur conservé comme connexion principale.
